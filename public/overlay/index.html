Overlays

Each overlay is its own page. Add the ones you want as separate sources, at 1920 × 1080 with a transparent background, and position or scene-switch them independently.

Style

OBS Studio

  1. Sources → + → Browser, and name it after the overlay.
  2. Paste the overlay's URL. Set Width 1920 and Height 1080.
  3. Leave "Shutdown source when not visible" off so it keeps receiving updates.

vMix

  1. Add Input → Web Browser, and paste the overlay's URL.
  2. Set the resolution to 1920 × 1080 and turn on Transparent if it's offered.
  3. Put it on an Overlay channel (1–4) to bring it on and off over your program.
